# Portfolio — François Gomez

Site portfolio personnel présentant mon parcours, mes compétences et mes projets.

## Accès

Le site est hébergé via **GitHub Pages** et accessible publiquement.

## Structure

```
├── index.html          # Page principale
├── assets/
│   ├── css/style.css   # Styles
│   └── js/main.js      # Interactions
└── README.md
```

## Personnalisation

- **Infos personnelles** : modifier directement dans `index.html`
- **Photo** : remplacer le placeholder dans la section "À propos"
- **Projets** : ajouter/modifier les cartes dans la section "Projets"
- **Parcours** : mettre à jour la timeline dans la section "Parcours"
- **Contact** : mettre à jour l'email et les liens sociaux

## Technologies

- HTML5 / CSS3 / JavaScript vanilla
- Google Fonts (Inter, Space Grotesk)
- Responsive design (mobile-first)
- Animations au scroll
