# Portfolio — François Gomez

> Facilitateur stratégique | Alternant GEMA | Porteur de méthode

Site portfolio professionnel multi-pages pour mettre en avant mon parcours, mes projets académiques, mon identité personnelle et mes 5 compétences clés (BUT GEA).

## Structure

```
├── index.html          # Accueil + À propos + Atouts + Contact
├── parcours.html       # Expériences Pro (Histoires 1-3)
├── projets.html        # Expériences Académiques (Histoires 7-9)
├── identite.html       # Expériences Personnelles (Histoires 4-6)
├── competences.html    # 5 UE avec liens vers les histoires
├── assets/
│   ├── css/style.css   # Charte graphique Finance (bleu marine, gris, blanc)
│   └── js/main.js      # Animations, menu mobile, compteurs
└── README.md
```
